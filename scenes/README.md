# Scenes

Each folder is one scene: `scene.py` (the code), `README.md` (what it is and how to play), `preset.json` (saved slider settings, if any) and `preview.png`.

Regenerate previews and this page with `python tools/make_previews.py`.

| Preview | Scene |
|---|---|

| ![grass](grass/preview.png) | **[Grass in the wind](grass/README.md)**<br>`python run.py grass`<br>Low-resolution field of grass blowing in the wind |
| ![hillside](hillside/preview.png) | **[Lakeside hillside](hillside/README.md)**<br>`python run.py hillside`<br>A painted lakeside hillside: tall grass and pink plumes in the summer wind |

| ![tallgrass](tallgrass/preview.png) | **[Tall grass, up close](tallgrass/README.md)**<br>`python run.py tallgrass`<br>A stand of tall grass seen from above and to the side; run your finger through it |
